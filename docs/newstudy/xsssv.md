# XSS跨站脚本攻击

## 存储型

1.恶意用户提交恶意内容到服务器（执行某些特殊操作的脚本代码），

2.服务器没有识别到，保存了这些恶意提交到数据库。

3.正常用户访问服务器，服务器在不知情的情况下将恶意信息返回，正常用户遭到攻击

简单防范：一般就写正则表达式进行脚本过滤，有第三方库xss可以进行过滤操作

## 反射型

1.恶意用户分享了一个正常网站的链接，链接里带有恶意内容

2.正常用户点击了该链接

3.服务器在不知情的情况下，将恶意信息读取了出来，正常用户受到攻击

简单防范：在渲染链接的a标签的href中加/，后续用绝对地址  或者在提交地址时进行过滤

## DOM型

恶意用户通过任何方式向服务器中注入了一些dom元素，从而影响了dom结构

正常用户访问时，运行的是服务器正常的js，但dom已改变，正常js读到了错误内容

简单防御：在模版引擎渲染时，全部使用=号，使恶意信息不再是正常dom。
